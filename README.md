# Leonex — Society Management System

Leonex is a Society Management System designed to simplify and organize the daily activities of a residential society. It aims to provide a centralized platform for managing residents, maintenance, complaints, visitors, and other society-related operations.

## Features

- **Resident Management:** Manage resident information and records.
- **Maintenance Management:** Organize maintenance charges and payment records.
- **Complaint Management:** Submit and track society complaints.
- **Visitor Management:** Maintain visitor entry records.
- **Facility Management:** Manage shared society facilities and bookings.
- **User Authentication:** Provide login access for authorized users.
- **Role-Based Access:** Support different access levels for administrators and residents, where implemented.
- **Dashboard:** Display relevant society management information.
